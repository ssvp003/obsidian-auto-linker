# Obsidian Auto Rename Linker Plugin

内部リンクの挿入や画像の貼り付け時に、自動的にエイリアス（表示名）やサイズ指定を補完する Obsidian プラグインです。

## 機能
- `[[ノート名]]` → 変更なし（Obsidian 標準）
- `[[ノート名.canvas]]` → `[[ノート名.canvas|ノート名]]` に自動変換
- `[[ノート名.base]]` → `[[ノート名.base|ノート名]]` に自動変換
- `[[ノート名#ヘッダー]]` → `[[ノート名#ヘッダー|ヘッダー]]` に自動変換
- **`![[画像.png]]` → `![[画像.png|500]]` などの画像サイズを自動補完（新規追加）**
  - ドラッグ＆ドロップやクリップボードから画像を貼り付けた際に、自動的に指定したサイズ（横幅）を挿入します。
  - 対応拡張子：`png`, `jpg`, `jpeg`, `webp`, `gif`, `svg`

## 設定項目
Obsidian の設定画面（コミュニティプラグイン一覧の「Auto Rename Linker」）から、以下の設定を変更できます。
- **デフォルト画像サイズ**: ノートに画像を貼り付けた際に自動設定される横幅（ピクセル）を自由に変更できます（デフォルト: `500`）。

## インストール方法
1. Obsidian の保管庫（Vault）の `.obsidian/plugins/` ディレクトリに `obsidian-auto-rename-linker` というフォルダを作成します。
2. そのフォルダの中に `manifest.json` と `main.js` を配置します。
3. Obsidian の設定 → 「コミュニティプラグイン」から「Auto Rename Linker」を有効化します。
